# Build the playlist

Once all five tracks exist in your Suno library:

1. Make sure every generation is **renamed to its track title**. Do this as you go —
   untitled takes are miserable to sort later.
2. Library → pick a track → **… menu → Add to Playlist → New Playlist**.
3. Name it, paste the description below, then add the other four.
4. Drag into running order: **01 → 05**.

## Playlist name

```text
From the Block Pushing Rocks to Free Phones Fresh Out the Box
```

## Playlist description

```text
West Oakland to a folding table with a banner on it. Five tracks on what the hustle costs, what it pays, and what happens when a man keeps the engine and changes the ignition. Strict bars. Heavy 808s. No singing.
```
