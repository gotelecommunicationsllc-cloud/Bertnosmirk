# CLAUDE.md

Claude Code loads this file automatically at the start of every session in this
repository. Its only job is to point you at the real context.

## Do this first

**Read `BERTNOSMIRK_HANDOFF.md` in full before doing anything else.**

That file is the single source of truth for this project: what it is, current state,
decisions already made, open questions, and a dated log of every prior session across
every AI tool.

## Do this last

Before the session ends, update `BERTNOSMIRK_HANDOFF.md` following the update protocol
in its Section 9, and commit the change. A session that does work without updating the
handoff file is an incomplete session.

## Rules

- Do not ask the user to re-explain anything already recorded in the handoff file.
- Do not maintain project notes anywhere else. One file, one truth.
- The handoff log (Section 8) is append-only. Never edit or delete past entries.
